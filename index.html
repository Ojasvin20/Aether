04 · Workflow thinking

From opaque AI runs to inspectable steps

A product-thinking study grounded in Capsule: represent a run as a sequence of model calls, tool actions, and state changes so a developer can identify where a result went wrong.

Workflow mappingDebuggabilitySystems thinking
