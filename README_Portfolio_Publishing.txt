HOW TO PUBLISH A PUBLIC PORTFOLIO LINK
Option A — GitHub Pages (free)
1. Sign in to GitHub and create a new public repository, e.g. ojasvin-ai-design-portfolio.
2. Rename the HTML file to index.html and upload it to the repository root.
3. Open repository Settings → Pages.
4. Under Build and deployment, select Deploy from a branch, choose main and /(root), then Save.
5. Wait for deployment and open the published URL shown in Settings → Pages.
6. Test the link in a private/incognito browser window before submitting.

Option B — Netlify Drop
1. Put the HTML file in a folder and rename it index.html.
2. Visit https://app.netlify.com/drop and sign in if asked.
3. Drag the folder onto the page to deploy.
4. Test the resulting public URL in a private/incognito browser window.
